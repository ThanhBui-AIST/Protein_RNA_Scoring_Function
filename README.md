# Protein_RNA_Scoring_Function

**Differentiation of RNA‒Protein Docking Structures Through Molecular Dynamics Simulation and Machine Learning Methods**

This approach distinguish the correct structure among many docking poses generated by docking methods such as Zdock, Autodock, Vina or machine learning-based methods such as AlphaFold3 and RosettaFoldNA.

This program takes the input of protein-RNA complex  and subsequently performs molecular dynamics (MD) simulation in order to estimate the stability of the structure. The machine learning classified model predicted structure as either near-native or non-native poses.
